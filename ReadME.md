## Project Links

### WeatherWeGo
Weather We Go is a multi-page weather application built with plain HTML, CSS, and JavaScript. It integrates NOAA and other free APIs to provide live weather data and forecasts. The project was originally deployed on Azure, then later refactored to use Netlify Functions for API handling and redeployed on Netlify after course access to Azure ended. It demonstrates real-world API usage and multi-environment deployment experience.

- **Visit Here:** [https://weatherwego2.netlify.app](https://weatherwego2.netlify.app)

### Cashify (Still in Progress)
Cashify is a personal finance tracking web app built with React, Vite, and JSX-based page components. It's deployed on Vercel and includes a custom AI-powered feature that generates personalized financial plans for users. The project focuses on clean UI, fast client-side performance, and a straightforward workflow for managing expenses and goals.

- **Visit Here:** [https://cashify20-65j5i0xdh-matthew-lindseys-projects.vercel.app](https://cashify20-65j5i0xdh-matthew-lindseys-projects.vercel.app)
